# 安居科技驗屋｜安居科技有限公司 官方網站專案（7 大專屬分頁企業官網版）

這是一套專為位於台中地區的 **「安居科技驗屋（安居科技有限公司）」** 量身打造的高規格、響應式（RWD）多頁式企業官方網站。網站設計與內容參考了台灣與台中頂尖驗屋機構之高水準配置，並符合公平交易委員會對驗屋證照廣告之真實性規範。
